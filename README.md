# Guess the Word

![image](https://github.com/user-attachments/assets/957e12ff-7485-4e34-a880-51d8f3ff5194)

A word guessing game based on hangman, built using React and TypeScript. It is hosted on Netlify [here](https://app.syntrice.com/guess-the-word).

## Setup

```bash
# 1. Clone the Repository
git clone https://github.com/Syntrice/guess-the-word.git

# 2. Resolve dependencies
cd guess-the-word
npm install

# 3. Run or build project
npm run dev # run in watch mode
npm run build # build only
```
